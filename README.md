# AI Worker Generator - Marketing Production Suite

## Overview
AI Worker Generator is a high-performance production suite designed specifically for ecommerce marketing agencies. It leverages cutting-edge generative AI to transform product concepts into world-class visual assets.

The tool is focused on efficiency, consistency, and professional quality, following the "Worker Agency" standards of excellence.

## Core Verticals

### 1. High-Performance Ad Generator (Best Ads)
Generate professional advertisements based on a library of "Winning Structures."
- **Blueprint-First Engine**: Uses high-detail JSON structures to ensure pixel-perfect adherence to designs.
- **Visual Master Guiding**: Injects reference thumbnails to guide the AI's layout and hierarchy.
- **Product Analysis**: Integrated Google Search tool for real-time product data extraction and Spanish localization.

### 2. E-com Image Variations
Transform raw product photos into professional lifestyle and studio photography.
- **Intelligent Contextualization**: Automatically extracts environments and tones from product URLs.
- **Consistent Quality**: Maintains brand integrity across diverse settings.

### 3. E-com Video Variations
Create cinematic short-form videos (8-25 seconds) using Google Veo.
- **Ready for Social**: Optimized for TikTok, Reels, and Meta Andromeda ads.
